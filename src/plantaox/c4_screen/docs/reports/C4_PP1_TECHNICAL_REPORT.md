# C4 PP1 Technical Report — PlantAOP-Screen

**Snapshot:** 19 October 2026 · **Presentation:** 21 October 2026 · **Freeze ID:** `c4_pp1_freeze_v1`  
**Evidence boundary:** generated outputs and tests cited below are verified repository artifacts. The production reference cloud and Function B signals remain MOCK.

## Executive summary

C4 turns four reviewed plant proteomes into 152,259 unique 3–20 AA candidates, imports the supplied ESM-2 Colab embeddings, computes AD tiers against a 500-sequence MOCK cloud, and produces deterministic mock-signal rankings, evidence cards, and an offline dashboard. It is a reproducible screening demonstration, not biological evidence or validated retrieval performance. The pipeline remains frozen to the currently embedded MOCK reference because embeddings for the newly staged C2-derived provisional cloud have not been generated.

## FR1 — Candidate generation

The inputs are taxonomy-filtered UniProt Swiss-Prot reviewed FASTAs for soybean (*Glycine max*; 3847), rice (*Oryza sativa* japonica; 39947), rapeseed (*Brassica napus*; 3708), and olive (*Olea europaea*; 4146). Source download records, release, dates, hashes, exclusions, and retained counts are documented in `SCREEN_PP1_Data_and_outputs.md` and the raw registry.

The implementation applies sequential complete cleavage with pyteomics rules `pepsin ph1.3` then `trypsin`, preserving parent coordinates. pH 1.3 is the nearest installed pepsin rule to the proposal's pH 1.2. This is a documented rule-based substitution for a BIOPEP-UWM batch workflow; no BIOPEP spot-check is claimed. Fragments are restricted to 3–20 residues, standard amino acids, and at least two distinct residue types. Exact sequence deduplication retains all parent accessions/positions. CD-HIT is not run in FR1: for <=9 residues, 90% identity permits no non-identical match; optional 10–20 AA clustering remains deferred.

## FR2 — Embedding and applicability domain

The supplied handoff manifest specifies `esm2_t33_650M_UR50D`, layer 33, mean residue pooling excluding BOS/EOS/PAD, 1,280 dimensions, float16 storage, N=152,259, and Tesla T4. The layer/pooling recipe is a C4 working assumption pending C1 confirmation. No ESM model was loaded locally. All candidate rows validated finite and in exact index order; import converts arrays to float32 for distance math.

Production cloud: 500 synthetic, composition-biased sequences with `source=mock_cloud`, seed 42. It is a placeholder, not curated biological truth. For `d_AD = 1 − cosine(candidate, cloud centroid)`, calibration uses leave-one-out cloud-member distances with a recomputed centroid and population standard deviation. `d_norm = min(d_AD/t2, 1)`.

## Function B — signals, scoring, ranking and cards

The current C1 SIM, C2 probability, and C3 BCS inputs are generated by `tests/c4_screen/fixtures/mock_signals.py`; every generated signal row and manifest states `source=mock`. The utility's latent AOP-like feature is a z-score over `3 × redox-residue fraction + 2 × hydrophobic fraction + short-length bonus (length <=10)`. `PROB_C2` is a clipped sigmoid of `-3 + 1.2z` plus heteroscedastic Gaussian noise; ten Tier 3 examples receive injected high mock probabilities. `SIM_C1` is a sigmoid of `0.8z − 0.8z(d_norm)` plus Gaussian noise. BCS strata sample IR/FSR and use `BCS=IR×(1−FSR)`. These are synthetic formulas, not C1/C2/C3 model outputs.

The observed mock Spearman correlations on 152,259 sequence-joined rows are SIM_C1/PROB_C2=0.462903, SIM_C1/d_norm=−0.693003, and PROB_C2/d_norm=−0.173945. They are descriptive diagnostics; the generator was not tuned to force target correlations.

The implemented score is `CS = w1·SIM_C1 + w2·PROB_C2·(1−d_norm)`, default `w1=w2=0.5`; Tier 3 is forced to CS=0. The `weight_sweep` helper runs `w1∈{0.25,0.5,0.75}` without mutating the default configuration. Ranking is per plant, descending CS, sequence tie-break. Cards carry provenance, descriptors, both mock signals, tier/distance, score/rank, length-bin BCS value, C4-provisional LOW/MEDIUM/HIGH flag, and injected-case metadata. Only Tier 1/2 enter top cards; Tier 3 is abstained/RED.

## Limitations, open decisions, and claim register

**Permitted claims:** four reviewed-proteome candidate generation; verified candidate/embedding counts and checksums; deterministic application of the stated C4 AD equations against the labelled MOCK cloud; deterministic mock-only integration behavior and test coverage.

**Do not claim:** that mock scores, rankings, or cards predict antioxidant activity or AOP relevance; that the MOCK cloud is a validated biological reference; that the ESM layer/pooling recipe is confirmed by C1; or that the prototype establishes plant safety/effectiveness. Retrieval evaluation is not performed on mock signals. PDSS, BIOPEP spot-check, chunked checkpointing, and C2 fold-0 scoring are deferred (PDSS is not meaningful against the current MOCK cloud). Supervisor acceptance and presentation/rehearsal are not implied by this technical report.

Open decisions: C1 confirmation of layer/pooling; C1 AOP-BenchPos replacing the provisional C2-derived real-cloud source; disjointness of reference and held-out evaluation sets; supervisor review of BCS cutoffs and any future domain metric; and known peptide-recoverability risk from pepsin digestion.
